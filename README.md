# QR Video Data Encoder/Decoder

This repository contains tools to encode arbitrary data into a video format using QR codes and then decode that video back into the original data. This includes command-line Go programs and a web-based decoder.

This project demonstrates a method for storing or transmitting data visually using QR codes compiled into a video stream.

## Subdirectories

-   **`/encode`**: Contains the `qrvidencode` Go program. This command-line tool takes an input file, splits it into chunks, encodes each chunk into a QR code (with header including checksum and sequence number), and then uses `ffmpeg` to compile these QR codes into a video file.

-   **`/decode`**: Contains the `qrviddecode` Go program. This command-line tool takes a video file (presumably generated by `qrvidencode`), extracts frames using `ffmpeg`, scans each frame for QR codes, validates them, and then reconstructs the original data.

-   **`/webdecode`**: Contains a web-based QR video decoder. This application runs in a browser, uses the screen capture API to watch a video (e.g., playing in another window or from a file), decodes QR codes in real-time, validates headers and checksums, and reassembles the original data. It's an alternative to the command-line `qrviddecode` for direct browser-based decoding.

## Core Idea

The primary goal is to convert binary data into a sequence of QR codes which are then displayed sequentially in a video. The decoder reverses this process. This can be useful for:

-   Data archival in a visual format.
-   Air-gapped data transfer (though a screen/camera setup).
-   Experiments in data encoding.

## Dependencies

The project relies on:

-   **Go** (version 1.18+ for modules) for the core logic. The project is structured as a single Go module at the repository root.
-   **`ffmpeg`** (must be installed and in system PATH) for video processing (creating videos in the encoder, extracting frames in the decoder).
-   Specific Go modules (see the root `go.mod` file) for QR code generation/scanning and checksum calculation.

Refer to the `README.md` file within each subdirectory for detailed instructions on using each program. Build instructions are generally performed from the repository root.
