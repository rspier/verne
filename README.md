# QR Video Data Encoder/Decoder

This repository contains a pair of Go programs to encode arbitrary data into a video format using QR codes and then decode that video back into the original data.

This project demonstrates a method for storing or transmitting data visually using QR codes compiled into a video stream.

## Subdirectories

-   **`/encode`**: Contains the `qrvidencode` program. This command-line tool takes an input file, splits it into chunks, encodes each chunk into a QR code, and then uses `ffmpeg` to compile these QR codes into a video file. Each chunk is prepended with a checksum and a sequence number for data integrity and ordered reconstruction.

-   **`/decode`**: Contains the `qrviddecode` program. This command-line tool takes a video file (presumably generated by `qrvidencode`), extracts frames using `ffmpeg`, scans each frame for QR codes, validates their checksums and sequence numbers, and then reconstructs the original data from the QR code payloads.

## Core Idea

The primary goal is to convert binary data into a sequence of QR codes which are then displayed sequentially in a video. The decoder reverses this process. This can be useful for:

-   Data archival in a visual format.
-   Air-gapped data transfer (though a screen/camera setup).
-   Experiments in data encoding.

## Dependencies

Both programs rely on:

-   **Go** (version 1.18+ for modules) for the core logic.
-   **`ffmpeg`** (must be installed and in system PATH) for video processing (creating videos in the encoder, extracting frames in the decoder).
-   Specific Go modules (see `go.mod` files in each subdirectory) for QR code generation/scanning and checksum calculation.

Refer to the `README.md` file within each subdirectory for detailed instructions on building, using, and understanding each program.
